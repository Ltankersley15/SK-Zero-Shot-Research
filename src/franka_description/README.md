# Franka FR3 Description

This workspace vendors a slim FR3-only subset of `franka_description` for the Isaac/MoveIt zero-shot manipulation stack.

The included files cover:

- FR3 URDF/SRDF xacro files
- Franka hand xacro files
- FR3 visual and collision meshes
- RViz/launch support used by the local MoveIt configuration

Other Franka robot variants from the upstream package are intentionally omitted to keep this repository focused on the active FR3 Isaac environment.
